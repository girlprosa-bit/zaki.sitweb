Production architecture

The implementation blueprint for the full Next.js, NestJS, PostgreSQL, Prisma, Redis, Socket.IO, Cloudinary, and Vercel/Railway stack.

Folder structure

apps/ web/ Next.js, React, TypeScript, Tailwind api/ NestJS modules and gateways packages/ ui/ shared components config/ eslint, tsconfig, tailwind presets types/ shared DTOs and contracts infra/ prisma/schema.prisma docker-compose.yml railway.json vercel.json

Core modules

AuthModule JWT, refresh tokens, RBAC UsersModule roles, teams, permissions ProjectsModule projects, tasks, subtasks, logs CrmModule clients, contacts, pipeline FilesModule Cloudinary signed uploads RealtimeModule Socket.IO rooms and events AutomationModule rules, queues, scheduled jobs ReportsModule exports, analytics, dashboards AiModule copy, planning, insights

Prisma schema sketch

User(id, name, email, role, passwordHash) Client(id, company, email, phone, industry, budget) Project(id, clientId, title, status, priority, dueDate) Task(id, projectId, columnId, title, assigneeId, dueDate) Comment(id, taskId, authorId, body, mentions) Attachment(id, projectId, url, type, version) Notification(id, userId, type, readAt) AuditLog(id, actorId, action, entity, metadata)

Realtime events

project.updated task.created task.moved comment.created file.uploaded notification.created typing.started approval.completed Socket rooms: organization:{id} project:{id} client-portal:{projectId}

Security

Rate limiting with Redis Argon2 password hashing JWT access tokens, rotating refresh tokens NestJS validation pipes and DTOs RBAC guards per route and gateway event Cloudinary signed upload presets Audit logs for sensitive actions Encrypted secrets and daily database backups

API routes

POST /auth/login POST /auth/register GET /dashboard/overview GET /projects POST /projects/:id/tasks PATCH /tasks/:id/move GET /clients POST /files/sign-upload GET /reports/performance POST /ai/generate-copy
