# 🔐 AgencyOS - منصة إدارة الوكالات الآمنة

## 📋 الميزات الأمنية

### 1️⃣ **فصل الأدوار (Role Separation)**
- ✅ لوحة تحكم منفصلة للمسؤول
- ✅ بوابة زبون محدودة الصلاحيات
- ✅ حماية الروابط بناءً على الدور

### 2️⃣ **المصادقة الآمنة (Authentication)**
- ✅ تسجيل دخول بـ JWT Token
- ✅ كود إذن خاص للمسؤول (Invite Code)
- ✅ تشفير كلمات المرور بـ bcryptjs

### 3️⃣ **حماية الرسائل والمكالمات**
- ✅ تخزين الرسائل المشفرة في قاعدة البيانات
- ✅ فصل كامل بين محادثات المسؤول والزبون
- ✅ سجل آمن لجميع المحادثات

### 4️⃣ **الحماية من الهجمات**
- ✅ CORS محمي
- ✅ validation على جميع المدخلات
- ✅ حماية من XSS و CSRF
- ✅ Token expiration

## 🚀 البدء

### التثبيت
```bash
npm install
```

### تكوين البيئة
```bash
cp .env.example .env
# عدّل المتغيرات في .env
```

### تشغيل الخادم
```bash
npm run dev
```

## 📁 البنية
```
server/
├── models/        # نماذج قاعدة البيانات
├── routes/        # المسارات والـ API
├── middleware/    # التحقق من المصادقة
└── index.js       # نقطة البداية

public/
├── js/
│   ├── auth.js    # نظام المصادقة
│   ├── messages.js # نظام الرسائل
│   └── ui.js      # إدارة الواجهة
└── index.html     # الصفحة الرئيسية
```

## 🔒 معايير الأمان

| الميزة | الوصف |
|-------|-------|
| JWT | مصادقة آمنة بدون جلسات |
| bcrypt | تشفير كلمات المرور |
| MongoDB | قاعدة بيانات آمنة |
| CORS | حماية الطلبات المتقاطعة |
| Validation | التحقق من جميع المدخلات |
